# Triage Labels

技能用语以五个规范 triage 角色为准。本文件把这些角色映射到本仓库 issue tracker 实际使用的标签字符串。

| 规范角色（技能库） | 本仓库 tracker 标签 | 含义 |
| ------------------ | ------------------- | ---- |
| `needs-triage`     | `needs-triage`      | 维护者需要评估此议题 |
| `needs-info`       | `needs-info`        | 等待报告者补充信息 |
| `ready-for-agent`  | `ready-for-agent`   | 规格完整，可供 AFK agent 执行 |
| `ready-for-human`  | `ready-for-human`   | 需要人类实现 |
| `wontfix`          | `wontfix`           | 不会处理 |

当技能提到某个角色（例如「打上 AFK-ready triage 标签」）时，使用本表对应的标签字符串。

编辑右侧列以匹配你实际使用的词汇。
